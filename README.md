# App Locker Legal & Verification Site

This repository hosts the public **Privacy Policy** and Google AdMob **`app-ads.txt`** verification file for **App Locker Pro** (`com.aistudio.applocker.kyzqpz`).

## Files Included
- `index.html`: Official Privacy Policy and Developer Contact info.
- `app-ads.txt`: AdMob publisher ownership verification file.

## GitHub Pages Deployment
1. Create a new public repository on GitHub (e.g., `prasad-dp.github.io` or `app-locker-site`).
2. Push the files in this directory to `main` branch.
3. Enable GitHub Pages under **Settings -> Pages -> Source: main / root**.
4. In **Google Play Console**, update your Website URL to `https://prasad-dp.github.io` (or your repository URL).
